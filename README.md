### 📌 Featured Projects

#### 🧩 [FrontendForge — AI-Powered Cloud Sandbox IDE](https://github.com/Satwaj/Capstone)
A cloud-native browser IDE built solo as 5 independently scalable microservices (auth, sandbox provisioning, AI orchestration, routing, notifications) on Kubernetes.
- On-demand per-user sandbox pods (Vite dev server + node-pty terminal agent) via the Kubernetes Client API, with Redis TTL-based auto-teardown after 20 minutes idle, and project files persisted to AWS S3
- A LangGraph ReAct coding agent (LangChain + Mistral AI) that reads, creates, and edits files directly inside live sandbox pods — streamed via Server-Sent Events, triggering Vite HMR for reload-free updates
- Wildcard NGINX Ingress routing and a custom WebSocket proxy for per-sandbox preview, HMR, and terminal traffic
- Google OAuth 2.0 + JWT auth, RabbitMQ event-driven notifications
- **Stack:** React, Vite, Node.js, Express, Docker, Kubernetes, MongoDB, Redis, RabbitMQ, LangChain, LangGraph, Mistral AI, AWS S3, NGINX Ingress

#### 🛒 [Snitch — MERN E-Commerce Platform](https://github.com/Satwaj/Snitch) · [Live Demo](https://snitch-nine.vercel.app)
A production-ready e-commerce platform with JWT + Google OAuth 2.0 auth, full catalog/cart/wishlist/checkout/order flow, and Razorpay payments with server-side signature verification.
- REST APIs backed by MongoDB Aggregation Pipelines for order analytics
- Search, filtering, sorting, and pagination across the product catalog
- Cloudinary for image storage, deployed on Vercel (frontend) + Railway (backend)
- **Stack:** React.js, Redux Toolkit, Tailwind CSS, Node.js, Express.js, MongoDB, JWT, Razorpay, Cloudinary

#### 🔍 [Arena AI — AI-Powered Search Assistant](https://github.com/Satwaj/Perplexity) · [Live Demo](https://perplexity-bay.vercel.app/)
A Perplexity-style research assistant combining LangGraph workflows, Pinecone-based RAG, and the Tavily Search API for real-time, web-grounded answers.
- Multi-LLM routing layer unifying Gemini, Groq, and Mistral behind a single interface, with a side-by-side model comparison mode
- **Stack:** React.js, Node.js, Express.js, MongoDB, LangGraph, LangChain, Pinecone, Gemini, Groq, Mistral, JWT
